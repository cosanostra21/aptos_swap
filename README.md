# aptos_swap

# Aptos USDC Swap Script / Скрипт свапа Aptos на USDC

🇷🇺 Этот код выполняет автоматические свапы на блокчейне Aptos, используя платформу [Liquidswap](https://liquidswap.com/).  
Он позволяет обменивать любые токены на USDC быстро и эффективно. Идеально подходит для ботов, DeFi-проектов или личного использования.

🇺🇸 This script performs automated swaps on the Aptos blockchain using [Liquidswap](https://liquidswap.com/).  
It allows you to swap any supported token into USDC quickly and efficiently. Suitable for bots, DeFi integrations, or personal use.

---

## Требования / Requirements
- Python 3.10+
